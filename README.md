# 한능검 시험지 생성기

한국사능력검정시험 심화 기출(47~79회, 1,650문항)로 단원 쪽지시험과 실전 모의고사를 만드는 웹페이지.

## 데이터 파일

- `questions.json`: 문항 1,650개. 「한능검 기출 편집기」에서 내보낸 것.
  - `id`: 회차-번호 (예: "47-01"), `r`: 회차, `n`: 번호, `score`: 배점
  - `topic`: 대주제 코드 (예: "01"), `code`: 소주제 코드 (예: "01-1"), `subj`: 소주제 이름, `blk`: 세분류 묶음
  - `q`: 발문, `src`: 자료 내용(텍스트로 옮긴 것), `kw`: 자료 키워드
  - `ch`: 선지 5개 배열. 각 선지의 `t`(선지 문장), `role`(정답/오답), `code`·`subj`(선지가 가리키는 소주제), `k`(선지 키워드)
  - `ans`: 정답 번호, `ansText`: 정답 선지 문장
  - `bogi`: 보기(ㄱ·ㄴ·ㄷ·ㄹ) 문장 배열, `neg`: 부정형 문항 여부, `type`: 문항 유형
  - `status`: 검수 상태 ("확인" 948개, "미검수" 702개)
  - `img`: 원본 문제 이미지 id (이미지 파일은 이 저장소에 없음)
- `taxonomy.json`: 시대 대주제·소주제·세분류 묶음 이름과 순서 (`topics`, `abc`, `rounds`)

## 만들 것 (1단계)

1. 범위 고르기: 대주제/소주제를 체크박스로 고르고, 문항 수를 정한다.
2. 무작위 출제: 고른 범위에서 문항을 뽑아 시대 순서(소주제 코드 순)로 정렬한다.
   - "검수 완료(확인) 문항만" 옵션
   - "실전 모의고사" 버튼: 전 범위 50문항, 실제 시험의 시대별 비율에 맞춰 출제
3. 시험지 화면: 번호, 발문, 자료, 보기, 선지 ①~⑤를 A4 인쇄에 맞는 2단 시험지 형태로 보여 준다.
4. 정답·해설지: 번호별 정답, 출처(회차-번호), 소주제, 자료 키워드를 표로 출력한다.
5. 인쇄 버튼: 시험지와 정답지를 각각 인쇄(PDF 저장)할 수 있게 한다.
6. 이미 출제한 문항 제외: 직전에 만든 시험지 문항을 빼고 뽑는 옵션.
